# Genesis Turma 01 — proposta pedagógica

**Abertura 09/01/2027** (semipresencial Anápolis + online). 8 semanas e 24 ateliers (três por semana); ajustar terça/quinta/sábado de acordo com calendário real a partir da abertura oficial. Pré-candidatura ≠ matrícula.

## Progressão
| Semana | Ateliers 1/2/3 | Entrega |
| --- | --- | --- |
| 1 | Ideia → identidade → primeira conversa | Primeiro agente e objetivos |
| 2 | Contexto → memória → privacidade | Base de conhecimento autorizada |
| 3 | Pesquisa → escrita → revisão | Artefacto útil verificável |
| 4 | Ferramentas → APIs → sandbox | Primeira capacidade reutilizável |
| 5 | Iniciativa → agendamento → aprovação | Rotina que propõe, não executa livremente |
| 6 | Papéis → colaboração → segurança | Equipa multiagente controlada |
| 7 | Projeto → testes → documentação | Protótipo com evidências |
| 8 | Melhorias → apresentação → Demo Day | Portefólio + roadmap pessoal |

## Três percursos de desafio
- **Novato / mobile-first:** Mentor de Estudos, Diário de Ideias, Organizador de Objetivos, Guia de oportunidades, comunicação e portefólio.
- **Mercado digital:** Catálogo Shopee/Mercado Livre a partir de dados fictícios, validação de anúncios, atendimento simulado, análise de margem, plano de operação multicanal; APIs reais só com consentimento e permissão.
- **Builder:** painel pessoal, skill de pesquisa, automação de arquivo, resumo de reuniões, pequeno serviço web, build/teste em sandbox, coordenação de agentes.

## Projeto coletivo
"Cidade Aumentada": equipas de serviços urbanos fictícios (comércio, turismo, formação, logística) interoperam via artefactos partilhados, sem copiar memórias privadas.

## Genesis Spotlight / Atlas Ventures
Até 3 projetos a avaliar para acompanhamento extra, somente se existirem capacidade e orçamento; eventual venture exige acordo específico sobre IP, investimento, remuneração e participação. Sem prémio de criação de empresa garantido.

## Inclusão
Ateliers de smartphones para dirigir agentes remotos; sessões com equipamento partilhado ou ambiente remoto para debug avançado. Bolsa e acesso não obrigam trabalho gratuito.
