# Contribuir

Contribuições são recebidas via issue ou PR; nunca em main diretamente. Respeitar primeiro docs/03_GOVERNANCE_AND_ACCESS.md e AGENTS.md.

Para alterações de código:
1. Escrever especificação breve e critério de aceite.
2. Criar branch; não alterar projetos irmãos.
3. Verificar npm run verify e anexar screenshots mobile/desktop.
4. Revisão humana de UX, acessibilidade, privacidade e permissões.
5. Não fazer merge nem deploy sem ordem de Sérgio.

SOULs e personalidades são rascunhos; uma alteração à Clara não modifica a Clara pré-existente na Holding. Os agentes em produção só são alterados por procedimento de deployment separado e autorizado.
